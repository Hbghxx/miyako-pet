# miyako —— Windows 桌面本地 AI 陪伴角色

miyako 完全运行在你自己的电脑上：不依赖云端服务，对话与记忆数据只保存在本机 `data` 文件夹里。

- **完全本地**：程序、聊天记录、记忆库全部在本机；零遥测，不收集、不上传任何使用数据
- **全 mock 可启动**：出厂零联网零密钥即可体验完整界面与对话闭环，模型层完全可插拔
- **接入即变强**：填一个 OpenAI 兼容 API 密钥（智谱 / DeepSeek / Ollama 本地模型等均可）即切换真模型
- **角色可插拔**：`data/characters/*.char` 多包共存、单活切换，支持导入 SillyTavern 酒馆卡

## 功能一览

| 功能 | 说明 |
|---|---|
| 文字 / 语音对话 | 输入框打字，或点 🎤 说话（本地 VAD 断句 + faster-whisper 本地识别） |
| 语音播报（TTS） | GPT-SoVITS 自训音色或云端克隆音色；服务不可用自动落纯文字 |
| 记忆与关系 | 聊过的重点进记忆库，长期相处积累好感/信任并影响语气 |
| 主动搭话 | 时段问候、闲置关心、识屏吐槽、陪玩模式、摄像头感知（均默认可关、过时机闸） |
| 工具模式 | 番茄钟 / 闹钟（每日+一次性）/ 倒计时 / 喝水久坐提醒 / 整点报时 / 节日问候 |
| 多角色 | 角色包单活切换；每角色独立记忆库；酒馆卡（.json/.png）一键导入 |

## 快速开始（Windows 10/11）

1. 双击 **`install.bat`** —— 自动寻找/引导安装 Python、创建运行环境、下载依赖（首次需联网），结束显示环境体检报告；
2. 双击 **`启动miyako.bat`** —— 服务端后台无窗口运行，桌面上出现角色立绘、托盘出现图标；
3. 出问题时双击 **`启动miyako(安全模式).bat`** 前台查看日志排查。

配置只有两个文件：`config\settings.yaml`（全部功能配置，带注释，参考 `config\settings.example.yaml`）与 `.env`（只放 API 密钥）。

## 数据外发透明度

miyako 本体零遥测。数据外发只有三类，全部由你自己配置开关：

1. 你主动填写的 AI 服务密钥（`.env`）—— 对话文本/画面/合成文本发往**你自己配置**的服务商；
2. 检查更新（默认关闭且未配置）—— 一次不含任何用户数据的 GET 请求；
3. 云端音色克隆 TTS（默认关闭）—— 待合成文本发往你配置的 TTS 服务商。

本地路径（语音识别、本地 OCR、记忆库、本地语音合成）永不外发。

## 卸载与数据

双击 **`卸载.bat`** 只删除运行环境（.venv）；`data\`（记忆与角色资产）、`config\settings.yaml`、`.env` 全部保留。备份 = 复制这三样。
